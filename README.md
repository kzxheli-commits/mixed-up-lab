# 乱序实验室 · MIXED UP LAB

3D 多人欢乐规则解谜游戏：把箱子变成椅子、把自己变成箱子、和朋友把整个实验室搞得一团糟，却莫名其妙完成了任务。

技术栈：`Three.js`（渲染） + `cannon-es`（物理） + `WebSocket`（Node.js 权威服务端） + 原生 ES Modules（零构建工具，随仓库分发 vendor 依赖）。

## 玩法

2~4 人进入荒谬实验室，目标：**启动实验室出口**。

1. **给疯狂实验员一把椅子** —— 用标签枪把箱子改成 `CHAIR`，或走侧室路线拿现成的。
2. **取回高台上的能源球** —— 垫箱子跳上去，或把箱子改成 `SPRING` 弹上去，办法不止一种。
3. **把能源球插入核心** —— 出口随即开启。
4. **逃出去** —— 最先按下出口开关的人触发结算，生成本局「实验报告」。

### 核心机制

- **标签枪**：改写物体标签，真实影响世界。`BOX → CHAIR` 让实验员收下你手里的箱子；`HEAVY ↔ LIGHT` 改变投掷手感；`STATIC → MOVABLE` 让固定物重新可搬。把**能源球改成椅子**照样能插进核心 —— 荒诞操作是被允许的，还会加混乱值。
- **缩放枪（Z/X）**：三档缩放（0.6x / 1x / 1.6x），物理质量随体积变化，保底贴地。
- **复制枪（G）**：复制任意普通物体，复制体 30 秒后消失 —— 垫脚、压板、堆料随你批量生产。
- **玩家物化（F）**：把自己变成箱子 15 秒，队友可以推着你去压压力板 —— 只有配合才能高效完成的行为。
- **压力板**：踩住开启侧室门。单人可以拖箱子压板，双人可以一个踩板一个进去拿 —— 谜题没有唯一解。
- **随机事件**（每 45~80 秒一轮，设计书 §25）：🐔 鸡群乱跑撞人、🔬 随机玩家变巨型、🌙 低重力 15 秒、🍌 香蕉皮滑飞你、💥 物体集体暴走 —— 事件表循环洗牌，同一张图每局体验都不同。
- **疯狂实验员**（设计书 §26）：头顶气泡实时说话，会转头盯着最近的玩家，鸡靠近 1.8m 内会吓得蹦跳躲开；交完椅子后台词池切换，对鸡入侵、低重力等事件有自己的吐槽。
- **程序化音效**：WebAudio 合成 18 种卡通音（biu、boing、鸡叫、滑倒、失控爆飞、通关连音……），零外部音频资源。
- **混乱值**：荒诞标签 +10、低重力 +10、物体暴走 +10、鸡群 +5、高速投掷/物化/踩香蕉 +3。冲到 90 进入 **CHAOS MODE**：全员弹飞、物体乱飞，一段时间后恢复 —— 混乱不是惩罚，是新的解法来源。
- **失败必须有趣**：本游戏没有 Game Over，实验报告记录标签/缩放/复制/物化/随机事件/踩香蕉/失控爆飞全部离谱数据并颁发称号。

### 操作

| 按键 | 动作 |
| --- | --- |
| WASD / 空格 | 移动 / 跳跃（点击画面锁定鼠标） |
| E | 智能交互：抓取 / 放下 / 交椅子 / 插核心 / 和实验员说话 |
| 左键 | 投掷手中物体 |
| 1-4 | 标签枪：`BOX` / `CHAIR` / `SPRING` / `LAMP` |
| R / T | 翻转 `HEAVY↔LIGHT` / `MOVABLE↔STATIC` |
| Z / X | 缩放枪：放大 / 缩小 |
| G | 复制枪（30 秒限时复制体） |
| F | 物化 / 解除（15 秒，有冷却） |
| Enter | 聊天 |

## 运行

```bash
npm install
npm start          # 默认 http://localhost:3000
```

浏览器打开 `http://localhost:3000`，创建房间后把 `http://<你的局域网IP>:3000` 发给朋友即可联机（2~4 人）。

| 环境变量 | 默认 | 说明 |
| --- | --- | --- |
| `PORT` | 3000 | HTTP + WebSocket 端口 |
| `EVENT_MS` | 40000 | 随机事件首触发延迟（毫秒），`0` = 禁用事件 |

## 测试

```bash
npm test
```

四个套件自动运行（自动拉起两台临时服务器与无头浏览器）：

- `check-dom.mjs` — DOM id / 资源引用 / 模块 import 静态校验
- `test-server.mjs` — 2 个 ws 客户端全流程通关：标签枪冷却与距离校验、物化、压力板、双谜题、荒诞混乱值、结算、断线
- `test-events.mjs` — 复制枪（关键物拒绝/冷却）、缩放枪（档位/冷却）、香蕉皮混乱上报、随机事件调度（`EVENT_MS=700` 短配置）
- `e2e-browser.mjs` — 无头 Edge 加载真实页面，CDP 驱动完整客户端通关（25 项断言：场景生成、抓取、标签视觉重建、物化、交椅、插核、出口、报告）

## 架构

```
server/
  index.js     HTTP 静态服务 + WebSocket 接入 + 10Hz 权威循环
  world.js     权威世界状态：房间、标签、谜题、物化、混乱值、随机事件、NPC AI、结算
client/
  index.html   大厅 / HUD / 结算
  js/
    level.js   关卡数据与台词池（两端共享，服务端 import 自此处校验距离）
    game.js    Three 场景 + cannon 物理世界 + 动态物体 + 远端玩家 + NPC 表现
    player.js  第三人称控制 + 相机 + 物化 + 香蕉/鸡接触反应
    interact.js 射线交互 / 抓取投掷 / 标签枪 / 缩放复制 / 智能 E 键
    audio.js   WebAudio 程序化音效（18 种）
    ui.js      HUD / 聊天 / 结算
    net.js     WebSocket 封装
    main.js    状态机 + 消息处理 + 主循环 + 上报
  vendor/      three / cannon-es（随仓库分发，无 CDN 依赖）
scripts/       测试套件
```

**权威模型**：服务器持有标签、谜题、物化冷却、混乱值与能力校验（距离/冷却全部服务端裁决），客户端只上报意图；错误一律服务器打回。

**同步模型**：位置 10Hz 快照，远端玩家插值；物理物体按**最近玩家分配模拟权**（`sim` 字段），模拟者上报位姿，其余客户端插值跟随 —— 抓取者优先获得模拟权。

**消息协议**（JSON over WebSocket）：

| 方向 | 消息 |
| --- | --- |
| C→S | `create` `join` `start` `pose` `objpose` `grab` `release` `throw` `tag` `scale` `copy` `morph` `unmorph` `interact` `chaosEvent` `chat` `leave` |
| S→C | `hello` `joined` `lobby` `roundStart` `snap` `ev`（tag/scale/spawn/despawn/morph/hold/consumed/puzzle/chaos/chaosMode/event/eventEnd/feed） `chat` `roundEnd` `error` |

## 开发阶段（按设计书）

- **P0 Prototype ✅**：第三人称移动、抓取/投掷、物理物体、标签系统与标签枪、玩家物化、任务系统、混乱值、第一张地图、基础多人同步、完整谜题闭环
- **P1 ✅（本轮）**：缩放枪、复制枪、随机事件五件套（鸡入侵/巨型玩家/低重力/香蕉皮/物体暴走）、事件专属测试
- **P1 ✅（第三批）**：NPC 动态化（看玩家/躲鸡/状态台词池）、程序化音效 18 种、实验报告统计完善（事件/复制/缩放/香蕉/爆飞 + 新称号）
- **P1 剩余**：更多谜题（设计书 §24 三按钮协作谜题）、NPC 会参与机关的深度动作
- **P2**：多地图、房间匹配、场景精修（设计书 §37-62 的卡通品质标准）
